# نقيلي (Naqeeli) 🎯

**تطبيق مقارنة أسعار ذكي للسوق المصري — دور، قارن، ووفّر.**

تطبيق Flutter (قيد التطوير) لتجميع أسعار المنتجات من المتاجر المصرية
ومقارنتها في مكان واحد.

## 🌟 المميزات

- 🔍 بحث ذكي في كل المتاجر
- 📊 مقارنة أسعار لحظية
- 🤖 مساعد توفير ذكي
- 📸 بحث بالصورة
- 🔔 تنبيهات انخفاض الأسعار
- ❤️ قائمة المفضلة

## 🛍️ المتاجر المستهدفة

### المتاجر الإلكترونية
- جوميا مصر (Jumia)
- نون مصر (Noon)
- أمازون مصر (Amazon)
- علي إكسبريس (AliExpress)

### المتاجر المحلية
- إكسترا (Extra)
- كارفور (Carrefour)
- بي تك (B.Tech)

## 🚀 التشغيل

```bash
flutter pub get
flutter run
```
